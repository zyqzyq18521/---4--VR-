做VR特效和做普通游戏特效，很多人以为区别在于“加个景深”“调个视野”。你按普通项目的思路把粒子拉满、辉光开到最大、后处理堆上去，导进头显一戴，三分钟就想吐。问题不在你特效做得不够炫，在于VR特效的第一性原理不是“好看”，是“不让人难受”。

普通游戏特效服务于屏幕里的画面，玩家和画面之间隔着一层玻璃。VR特效服务于一个戴着显示器的人，他的眼睛被完全包裹，他的前庭系统和视觉信息直接打架。任何在屏幕上“很酷”的东西——镜头震动、剧烈的空气扭曲、高饱和的闪光——在头显里都可能变成生理不适的触发器。4A Games的资深特效师在开发《ARKTIKA.1》时总结得很直接：VR玩家有极高的行动自由度，你无法预测他的视角；90帧的硬性要求限制了创作自由；编辑器里看着完美的效果，头显里可能完全不是那回事。

第一个差异：特效不能“控制镜头”，只能“欺骗环境”。

普通游戏里，爆炸时镜头一震、画面一晃，玩家觉得很爽。VR里做这件事是自杀。镜头震动意味着玩家看到的世界在动，但他的身体没动，这种视觉与前庭觉的冲突是晕动症最直接的来源。正确的做法是：让世界动，不让镜头动。

4A Games在《ARKTIKA.1》里用了一个很聪明的替代方案：需要制造“冲击感”的时候，他们让碎石从上方落下、让灰尘从地面升起，玩家站在中间感受周围的运动，但相机本身保持稳定。你不需要真的推玩家一把，你只需要让环境替他反应。

第二个差异：空气扭曲是双刃剑，用错地方就是晕眩制造器。

扭曲效果在普通游戏里几乎是标配，枪口焰周围来一点、爆炸冲击波来一点、热浪来一点，画面显得有“能量感”。但在VR里，扭曲直接作用于玩家的视觉感知，而玩家的视野里没有“屏幕边框”作为缓冲，扭曲会直接影响平衡感。

4A Games的准则很明确：枪口焰周围不要加扭曲，哪怕你在编辑器里看着觉得“还好”，头显里感觉完全不同。扭曲可以用在血浆、液体折射这类有明确物理逻辑的地方，但不能用在高频、重复、贴近玩家视野的视觉事件上——开枪是VR里最高频的动作，每一次开枪都扭曲一下，玩家撑不过一梭子子弹。

第三个差异：特效必须从“每一个角度”成立，不存在“最佳机位”。

普通游戏特效师有一个隐形的靠山：相机是固定的，或者至少是可控的。你可以设计一个从某个特定角度看最帅的炮口焰，玩家在游戏里看到的视角和你设计时看到的视角基本一致。

VR没有这个靠山。玩家可以把枪口对准任何方向，歪着头看、侧着看、把枪转过来看。你在编辑器里调了一个完美的“第一人称视角”炮口焰，玩家把武器转一下，那个特效就垮了，像一张纸片。4A Games的解法不是做一个更复杂的特效，是把特效拆成几个简单的固定部分，每个部分都有三维的显示效果，这样无论玩家从哪个角度看，至少有一个部分是成立的。复杂不等于好，覆盖所有角度才等于好。

第四个差异：性能预算不是“尽量优化”，是“11毫秒的死刑判决”。

普通游戏掉几帧，玩家可能察觉不到。VR掉帧的后果是直接的身体反应：眩晕、恶心、头疼。90Hz头显意味着每一帧的渲染预算只有大约11.1毫秒。粒子效果是帧率波动的主要元凶之一，因为粒子数量大、更新频率高、而且透明混合需要每帧重新计算。

这意味着VR特效的“好看”必须建立在“省”的基础上。4A Games的做法是极致复用：同一个蒸汽特效，用同一张静态纹理，靠旋转、运动、alpha通道和颜色曲线做出不同的效果。Unigine的VR开发文档也强调，如果可以用多边形几何体代替decal，就用几何体；透明渲染在VR里代价极高，能不用就不用。你的素材库大小不决定你的特效质量，你对一张纹理的压榨程度才决定。

回到开头那句话。做普通游戏特效，你问的是“这个效果够不够炸”。做VR特效，你问的是“玩家戴着这个玩意看三分钟，会不会想摘下来”。沉浸感的代价是舒适度，而舒适度的底线是帧率和生理安全。 你的特效可以不够华丽，但不能让人难受。一个在头显里稳定跑满90帧、从任何角度看都成立、开枪时不扭曲视野的普通炮口焰，比一个在编辑器里惊艳但戴上就晕的“大作级”特效，更接近商业可用的标准。

先跑通“不让人难受”这条线，再谈“让人惊艳”。今天就把你手头那个VR特效的扭曲强度调低一半，把粒子数量砍掉三成，看看戴上头显之后，你的第一反应是“还行”还是“快摘”。
